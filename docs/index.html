The on-device model writes a memo for all 12 files. Code checks each one. A memo with a wrong number, a sentence with no source, or a changed outcome is blocked.

Why the AI runs in the browser

Borrower files hold bank statements and tax data. Here the model is downloaded once and runs on this device through WebGPU, so no file leaves the laptop and no API key is needed. Code, not the model, decides every result, so a small model is enough: its job is only to write.

Model: open-source, via WebLLM. Needs a browser with WebGPU (recent Chrome or Edge on desktop).
