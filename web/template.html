AI memo test (runs on this device)

Code writes an outline of each memo and decides what goes where. The on-device model only rewords it in plainer English; it never types a number. Code fills the figures back in and checks the result. A wrong figure, a sentence that contradicts a rule's result, a sentence with no source, or a changed outcome is blocked, and the model gets up to 3 tries. The table shows how often it needed more than one.

Why the AI runs in the browser

Borrower files hold bank statements and tax data. Here the model is downloaded once and runs on this device through WebGPU, so no file leaves the laptop and no API key is needed. Code, not the model, decides every result, so a small model is enough: its job is only to write.

Model: open-source, via WebLLM. Needs a browser with WebGPU (recent Chrome or Edge on desktop).
